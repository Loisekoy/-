# Fitness Tracking Management System

本目錄保留早期 React / FastAPI 原型作為參考；本次教師建議修訂與正式驗收對應的現行版本為 [`php-app`](./php-app/README.md)。

## 現行版本

- Frontend：同源 HTML / CSS / JavaScript
- Backend：PHP 8.4 + PDO
- Database：PostgreSQL 16
- Deployment：Docker + Render Blueprint
- Schema：20 張應用資料表、25 條外鍵
- 正式規格書：`output/specification/`
- 資料庫與口試操作手冊：[`docs/操作手冊_資料庫與口試準備.md`](./docs/操作手冊_資料庫與口試準備.md)
- 教師建議追蹤：`docs/TEACHER_REVIEW_TRACEABILITY.md`
- 修訂記錄：`CHANGELOG.md`

實作、環境變數、Migration、測試與排程說明請以 [`php-app/README.md`](./php-app/README.md) 為準。
